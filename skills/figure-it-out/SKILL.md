# Figure it out

Write the user's outcome, constraints, done condition, and unknowns. Identify the cheapest observation that resolves the highest-impact uncertainty. Build a task-specific sequence of verifiable units, recording inputs, outputs, acceptance checks, and stop conditions. Execute the first observation before creating extensive infrastructure.

Update the plan when evidence changes the premise. Prefer a small rerunnable tool for bulk work. Do not treat an autonomy request as permission to expand scope, spend indefinitely, or perform unrelated external actions. Finish with the produced artifact, checks, remaining gaps, and any decision requiring the user.
