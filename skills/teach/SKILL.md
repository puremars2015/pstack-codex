# Teach

Use how to ground the behavior and why when history matters. Start from a concrete input and walk through observable outputs and state changes. Explain each abstraction when it becomes necessary. Use a small diagram or executable example when it clarifies a boundary. Separate what the code proves from historical inference. Adapt depth to the user's knowledge and end with the useful consequence, not a jargon recap.
