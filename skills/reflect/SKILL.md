# Reflect

Read the task's actual attempts, evidence, corrections, and final outcome. Separate a recurring lesson from an incidental failure. Prefer correcting an architecture, type, validator, or small script over adding prose. If a skill change is useful, read the available skill-creator guidance and edit the source rather than the installed cache.

Compare the proposed lesson against a counterexample so it does not become a universal rule from one task. Validate changed artifacts. Report the evidence, narrow change, and how to verify it. Do not mine unrelated history or open an unsolicited PR.
