# Autonomous run

Read [the runtime contract](../references/codex-runtime.md) first.

Define done, scope, time/cost boundary, and external actions already authorized. Maintain a plan and decision log. Execute and verify successive units, changing hypotheses when evidence refutes them. Stop on completion, user stop, an exhausted boundary, or an actual required decision. Do not interpret autonomy as permission for unrelated messaging, scheduling, deployment, or destructive actions.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
