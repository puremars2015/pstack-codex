# Prototype

Read [the runtime contract](../references/codex-runtime.md) first.

Write the competing hypotheses and the observation that distinguishes them. Build minimal isolated sketches using actual inputs and tools. Compare the decisive behavior or measurement rather than polishing the sketches. Record the result and dispose only of scratch artifacts created for the task when appropriate. Production implementation is a separate scoped step.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
