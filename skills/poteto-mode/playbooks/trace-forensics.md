# Trace forensics

Read [the runtime contract](../references/codex-runtime.md) first.

Identify artifact type, capture method, sampling limits, and workload. Read with a supported parser or viewer. Distinguish inclusive from self cost and CPU from waiting. Locate representative stacks and map them to the correct source version. State what the capture establishes and what needs a new run; never fabricate missing samples.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
