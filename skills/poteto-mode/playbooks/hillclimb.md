# Hillclimb

Read [the runtime contract](../references/codex-runtime.md) first.

Agree the metric, target, workload, correctness constraints, and run/time boundary. Freeze a trustworthy harness using benchmark-checklist and keep raw observations. Change one hypothesis per experiment. Keep only repeatable wins that preserve correctness; revert rejected changes without disturbing user work. Log decisions and stop at the target, budget, or evidence-backed plateau.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
