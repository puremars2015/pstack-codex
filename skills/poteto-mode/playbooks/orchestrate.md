# Orchestrate

Read [the runtime contract](../references/codex-runtime.md) first.

Model phases, dependencies, ownership, shared resources, and completion evidence. Use permitted collaboration workers for independent bounded slices; otherwise run the dependency graph sequentially. Keep a durable status artifact, inspect each delivered unit, and reconcile integration conflicts. A project role is not tied to a particular agent. Do not create sidebar chats or scheduled wakeups without an explicit request.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
