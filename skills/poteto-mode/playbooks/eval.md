# Eval

Read [the runtime contract](../references/codex-runtime.md) first.

Define observable success criteria and representative cases before comparing variants. Use isolated outputs, identical inputs, and blinded labels where feasible. Fix the environment and record model/settings actually used. Compare task outcomes, cost, failure types, and variance. Do not infer broad superiority from one anecdote; report what the sample supports.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
