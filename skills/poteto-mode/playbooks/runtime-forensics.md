# Runtime forensics

Read [the runtime contract](../references/codex-runtime.md) first.

Reproduce the live symptom and record environment and timing. Capture focused instrumentation with tools actually available on the platform. Correlate runtime events with source paths and test competing causes. Keep investigation overhead out of reported performance samples. Deliver the evidenced cause and confidence; implement a fix only when requested.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
