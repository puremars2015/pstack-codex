# Authoring a skill

Read [the runtime contract](../references/codex-runtime.md) first.

Read the available skill-creator instructions. Define the requests the skill should handle and avoid attracting unrelated work. Keep essential decisions in the entrypoint and conditional detail in references. Validate frontmatter, references, available tools, and realistic behavior. Preserve user authorization and edit the source package rather than installed cache files.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
