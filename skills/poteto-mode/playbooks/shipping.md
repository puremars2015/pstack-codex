# Shipping

Read [the runtime contract](../references/codex-runtime.md) first.

Confirm the exact branch/PR chain and applicable merge authorization. Review every candidate head and its actual checks independently where permitted. Recheck head and base immediately before any merge; any new patch invalidates affected verification. Land only the contiguous verified portion in dependency order using available GitHub tooling. Without merge authorization, finish with a reviewable ready state and the precise remaining action.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
