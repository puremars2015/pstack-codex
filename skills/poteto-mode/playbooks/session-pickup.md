# Session pickup

Read [the runtime contract](../references/codex-runtime.md) first.

Read the available handoff, decision log, relevant chat, and current working tree. Record dirty files, revision, running processes, and artifacts before acting. Reconcile planned versus implemented work and revalidate stale claims. Continue from the actual unfinished unit without redoing completed work. Do not assume another chat can be messaged or owns the current checkout.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
