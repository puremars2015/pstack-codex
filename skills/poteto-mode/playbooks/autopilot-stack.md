# Autopilot stack

Read [the runtime contract](../references/codex-runtime.md) first.

Define the stack topology and per-layer acceptance checks. Implement small ordered commits with clear base branches. Verify each layer and the integrated stack. Use opening-a-pr only when PR publication is in scope. Deliver the chain, validation, and remaining concerns for the user to review and land; this workflow does not imply merge authorization.

Finish with the outcome, concrete evidence, and any remaining work. Do not invent unavailable tooling or silently skip a required check.
