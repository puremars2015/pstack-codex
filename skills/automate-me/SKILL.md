# Personal workflow

Use only relevant accessible task history. Identify repeated decision patterns, desired evidence, and user corrections; distinguish preferences from one-off instructions. Draft a named personal skill that routes to installed pstack skills where useful. Follow the available skill-creator guidance, keep the workflow scoped, and validate frontmatter and references.

Do not automatically enable a universal mode, add a scheduled job, or inspect private chat databases. Present the concrete skill and what preferences it encodes. Install it only within the requested scope and preserve existing skill files.
